# نجات سرباز رایان

همراه روزبه‌روز مامان و بابای رایان، از دوران بارداری تا بزرگ شدن. ساخته‌شده با Next.js و React، برای انتشار روی ورسل.

## بخش‌ها

- **امروز:** کارهای روزانه، جدا برای بابا و مامان، نکته‌ی روز، پیشرفت همسر، کار این هفته و ماموریت بعدی رایان
- **هفته‌ها:** کار مهم هر هفته‌ی بارداری (۱۴ تا ۴۱) برای بابا و مامان، با اندازه‌ی رایان در هر هفته
- **رایان:** ماموریت‌ها و «اولین‌ها» از قبل از تولد تا ۱۸ سالگی؛ هر ماموریت با تاریخش یه مدال می‌گیره و درجه‌ی رایان بالا می‌ره. بخش «آینده‌ی رایان» هم ماشین‌حساب پس‌انداز داره.
- **یادگیری:** تغذیه، مراقبت از رایان، چک‌لیست تولد، نوروز با نوزاد، مامان و بابا، سالم و با اعتمادبه‌نفس
- **مشاور:** سؤال‌های بارداری، مراقبت و رشد رایان رو از هوش مصنوعی بپرسید (اختیاری، پایین‌تر توضیح داده شده)
- **نامه‌ها:** نامه‌های بابا و مامان به رایان

## راه‌اندازی روی ورسل

### ۱. انتشار اولیه
1. در [vercel.com](https://vercel.com) روی **Add New → Project** بزنید.
2. مخزن `saving-private-ryan` رو انتخاب کنید (Import). ورسل خودش تشخیص می‌ده Next.js ـه. روی **Deploy** بزنید.
3. چند دقیقه بعد آدرس اپ آماده‌ست. در این مرحله اپ کار می‌کنه، ولی اطلاعات فقط روی همون گوشی ذخیره می‌شه.

### ۲. فعال کردن حالت دونفره (رایگان)
1. در صفحه‌ی پروژه در ورسل، به تب **Storage** برید و **Create Database** رو بزنید.
2. **Upstash** و بعد **Upstash for Redis** رو انتخاب کنید، پلن **Free** و نزدیک‌ترین منطقه (مثلاً Frankfurt).
3. پایگاه داده رو به همین پروژه وصل کنید (**Connect**، برای همه‌ی محیط‌ها). ورسل خودش متغیرهای `KV_REST_API_URL` و `KV_REST_API_TOKEN` رو می‌سازه.
4. به تب **Deployments** برید، روی آخرین انتشار سه‌نقطه رو بزنید و **Redeploy** کنید. متغیرهای جدید فقط بعد از انتشار دوباره اعمال می‌شن.

اگه اسم متغیرها در پروژه‌تون فرق داشت، از **Settings → Environment Variables** این دو رو با مقادیر Upstash بسازید: `KV_REST_API_URL` و `KV_REST_API_TOKEN` (اسم‌های `UPSTASH_REDIS_REST_URL` و `UPSTASH_REDIS_REST_TOKEN` هم قبول می‌شن).

### ۳. ساختن خانواده و دعوت همسر
1. اپ رو باز کنید؛ صفحه‌ی خوش‌آمد میاد. نقش و سن بارداری رو انتخاب کنید و «بزن بریم!» رو بزنید.
2. از **تنظیمات** (چرخ‌دنده‌ی بالا) **ساختن لینک دعوت** رو بزنید و لینک رو برای همسرتون بفرستید.
3. همسرتون لینک رو باز می‌کنه و نقشش رو انتخاب می‌کنه. هر لینک فقط یک بار کار می‌کنه و ۷ روز اعتبار داره.

برای گوشی دوم خودتون هم می‌تونید همین‌طور لینک بسازید.

### ۴. روشن کردن مشاور رایان (اختیاری)
مشاور با هر سرویسی که API سازگار با OpenAI (`/chat/completions`) داره کار می‌کنه. از **Settings → Environment Variables** در ورسل این‌ها رو اضافه کنید و بعد **Redeploy** کنید:

| متغیر | مقدار |
| --- | --- |
| `AI_BASE_URL` | آدرس API سرویس، تا قبل از `/chat/completions`، مثلاً `https://…/v1` |
| `AI_API_KEY` | کلید API |
| `AI_MODEL` | اسم مدل (پیش‌فرض: `gpt-4o-mini`) |
| `AI_DAILY_LIMIT` | سقف سؤال‌های هر خانواده در روز (پیش‌فرض: ۳۰) |

نکته‌ها:
- مشاور فقط برای اعضای خانواده کار می‌کنه، یعنی اول باید مرحله‌ی ۲ (Upstash) انجام شده باشه.
- کلید فقط در سرور استفاده می‌شه. هیچ‌وقت اسم متغیر رو با `NEXT_PUBLIC_` شروع نکنید.
- به سرویس فقط سؤال، چند پیام قبلی همون گفتگو، نقش (بابا یا مامان) و هفته‌ی بارداری یا سن رایان فرستاده می‌شه. گفتگو در سرور اپ ذخیره نمی‌شه، ولی سرویس هوش مصنوعی خودش ممکنه سؤال‌ها رو نگه داره؛ اطلاعات شخصی ننویسید.
- اگه سؤال به علامت خطر اشاره کنه (مثل تب نوزاد، خونریزی یا کم شدن حرکات)، اپ قبل از هر جوابی پیام تماس با پزشک و ۱۱۵ رو نشون می‌ده.
- اگه سرویس جواب نده، اپ جواب ساختگی نمی‌ده و فقط خطا رو نشون می‌ده.

### ۵. نصب روی صفحه‌ی گوشی
- **اندروید (Chrome):** منوی سه‌نقطه، **Add to Home screen** یا **Install app**
- **آیفون (Safari):** دکمه‌ی اشتراک‌گذاری، **Add to Home Screen**

### دسترسی از ایران
گوشی‌ها فقط به سایت ورسل وصل می‌شن و ارتباط با پایگاه داده از سمت سرور ورسل انجام می‌شه. اگه دامنه‌ی `vercel.app` بدون VPN باز نشد، معمولاً وصل کردن یه دامنه‌ی شخصی از **Settings → Domains** مشکل رو حل می‌کنه.

## حریم خصوصی و امنیت
- ورود با ایمیل یا رمز نیست. هر دستگاه بعد از ساختن خانواده یا باز کردن لینک دعوت، یه کلید تصادفی در یه کوکی امن (httpOnly) می‌گیره. در سرور فقط هش این کلید نگه داشته می‌شه.
- لینک‌های دعوت یک‌بارمصرف‌ان و بعد از ۷ روز باطل می‌شن.
- هر کس فقط نامه‌های خودش رو می‌تونه پاک کنه. تیک‌های روزانه بعد از ۱۲۰ روز خودکار پاک می‌شن.
- «خروج این دستگاه» در تنظیمات، دسترسی همون دستگاه رو از خانواده حذف می‌کنه.

## توسعه

```bash
npm install
SPR_DEV_MEMORY=1 npm run dev   # حالت دونفره با حافظه‌ی موقت (فقط برای توسعه)
npm run dev                    # حالت «فقط همین دستگاه»
npm run typecheck
npm run build
```

### اضافه کردن مطلب تازه
- کار هفتگی: `content/weeks.ts`
- کارهای روزانه و نکته‌ها: `content/daily.ts`
- ماموریت‌های رایان و درجه‌ها: `content/missions.ts`
- چک‌لیست‌ها: `content/lists.ts`
- بخش‌های یادگیری: `content/learn.ts` و `components/learn/`

شناسه‌ی هر کار یا ماموریت (مثل `m-smile`) تیک‌های ذخیره‌شده رو بهش وصل می‌کنه؛ شناسه‌های موجود رو عوض نکنید.

نسخه‌ی قدیمی تک‌فایلی در `legacy/standalone.html` نگه داشته شده.
